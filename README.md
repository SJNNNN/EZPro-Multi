# EZPro-Multi
EZPro-Multi: Contrastive learning-enhanced multi-property prediction for enzyme engineering

## Requirements
  * python==3.7
  * dgl==0.6.1
  * networkx==2.5
  * numpy==1.16.6
  * scikit-learn==0.20.3
  * pytorch==1.5.0
  * tqdm==4.15.0

## File
### code
  * train.py: Train the model
  * model.py: Structure of the model
  * predict_kcat.py:predicts kcat values
  * predict_ddg.py: predicts ΔΔG (ddG) values
  * predict_sol.py: predicts protein solubility change (Δsol) values
 
## Usage
  * download code and data
  * execute ```python eval.py```
